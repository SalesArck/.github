# Security

Report a vulnerability to [work@doshidhruv.com](mailto:work@doshidhruv.com). Include the repository, the affected surface, and a short reproduction. Do not include live tokens, service-role keys, or customer data in the email.

Do not file a public GitHub issue for:

- secrets, API tokens, or database URLs
- a way to read another tenant's data
- a way to change wallet balances outside the normal earn and redeem flow

We will reply to confirm we received the report. Production fixes ship after they have been checked on the non-production environment, unless the exposure is active.

Supported surfaces:

- [loyalty.salesarck.com](https://loyalty.salesarck.com)
- [salesarck.com](https://salesarck.com)
- The SalesArck API on Render
- Private repositories in the SalesArck organization
